Custom Domain Setup — rvsree-labs.dev

Manual steps to register the domain via the AWS Console, turn off auto-renewal immediately, and (once registered) point it at this project's App Runner service. Do this directly yourself — it needs your real contact/billing info.

Billing reality, stated plainly: this is a real ~$17 charge for a full year, paid upfront, generally non-refundable. There is no "pay and cancel for a refund" — what you can do is register it, then immediately turn off auto-renewal so it simply expires after 12 months and never charges again. Confirm AWS's exact refund policy on their own billing page if that matters to you before paying - don't take my word for it.

Part 1 — Register the domain

  1. Go to console.aws.amazon.com → sign in
  2. In the top search bar, type Route 53 → open the Route 53 service
  3. Left sidebar → Registered domains
  4. Click Register domains
  5. In the search box, type rvsree-labs.dev → click Search
  6. Confirm it shows as available with a price around $17.00/yr → click Add to cart
  7. Click Continue

Contact information form

ICANN requires this for every domain, for three roles: Registrant, Administrative, Technical. Route 53 lets you fill it once and copy it to all three (there's an "Also use for Administrative/Technical contact" checkbox — use it, no need for three separate people).

  • Full name
  • Email address
  • Phone number — international format, e.g. +1.5551234567 (country code, dot, number, no spaces/dashes)
  • Address: street, city, state, ZIP/postal code, country
  • Privacy protection: leave this enabled (it's on by default and free for .dev) — your real contact info stays out of public WHOIS lookups
  1. Click Continue
  2. Review everything on the summary page
  3. Auto-renew — it's enabled by default on this screen. You can leave it on for now and disable it in Part 2 right after, or look for the toggle here and turn it off immediately if this version of the console offers it directly
  4. Check the box agreeing to the registrant agreement
  5. Click Submit / Complete Order — this is the actual charge

Registration isn't always instant — AWS sends a confirmation email, and the domain typically shows as fully registered in the console within a few minutes to a few hours.

Part 2 — Turn off auto-renewal (do this right after, don't skip)

  1. Route 53 → Registered domains → click rvsree-labs.dev
  2. Find Auto renew (usually near the top of the domain's detail page)
  3. Toggle it to Disabled / click Disable auto renew
  4. Confirm the change

You now have the domain for a full year, and it will not charge again after that — it will simply expire unless you manually renew it later.

Part 3 — What happens next (I'll do this part)

Once the domain shows as registered, let me know and I'll associate it with this project's App Runner service:

  • aws apprunner associate-custom-domain — tells App Runner about the domain, e.g. as hrb-chatbot.rvsree-labs.dev (a subdomain, keeping the bare domain free for other projects later, per the earlier plan)
  • AWS hands back a few DNS records (validation + routing) to add
  • Since the domain is already in Route 53, I can add those DNS records directly via the CLI — no manual DNS editing needed on your end
  • AWS auto-issues an SSL certificate for the new domain - no separate cert work
  • Takes a few minutes to a few hours to fully validate and go live

After that, https://hrb-chatbot.rvsree-labs.dev works as a clean alias for the existing https://mrgysvt6ye.us-east-1.awsapprunner.com URL - both will keep working.
